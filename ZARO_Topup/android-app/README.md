# ZARO Android App

The mobile UI is based on the design image supplied in this conversation: black/orange/yellow ZARO identity, branded header, promotional hero, game tiles, Arabic/English toggle, and fixed five-item bottom navigation.

## Build APK
Open the repository's **Actions** tab, run **Build ZARO Android APK**, then download the `zaro-android-apk` artifact from the completed workflow.

## Scope
This build is a UI prototype. Orders, payments, supplier API, account login, support messaging, and admin functions are not connected yet. Game artwork and logo are loaded from the existing ZARO storefront.
